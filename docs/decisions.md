Последствия: мёрж в `main` = публикация, поэтому мёржит владелец или назначенный интегратор (см. `AGENTS.md`). Нужен секрет репозитория `VERCEL_TOKEN` (токен Vercel пользователя; добавляет владелец репо, в Git и документы не попадает). ## DEC-014 · 2026-10-30 · принято (sol0139; план одобрен владельцем Ярой в PR #9); закрывает DEC-008

**Supabase для входа, данных кампаний, реального времени и карт.** Своего сервера нет: браузер говорит с Supabase через `@supabase/supabase-js` 2.118.0, подключённый ES-модулем с jsDelivr с точной версией (сборщик не вводится, DEC-002). Проект `tavern` (`ilsuespohsuligyiqjsx`, eu-central-1) — в отдельной бесплатной организации `rasputye`; приложение Discord «Распутье» — отдельное. С DnD Kids (`dnd-novice`) нет ничего общего: ни организации, ни пользователей, ни ключей, ни хранилища.

- **Вход** — Supabase Auth, провайдер Discord, PKCE; берём ник и аватар (scope `identify`). Вход по почте выключен. Секрет приложения Discord хранится только в панели Supabase.
- **Права проверяет база.** Роль — из членства в кампании (`campaign_members`). RLS на всех таблицах; то, что игроку можно сверх своей строки (вступить по коду, выбрать героя, дописать исследованные клетки), — функции Postgres `security definer`; тонкие правила (двери, чужие токены при открытом перемещении, действия в бою, спасброски) — триггеры. Проверка — `supabase/tests/rls.sql` (88 сценариев, транзакция с откатом). Решение sol0139 30.10 09:19: в бою игрок может бросать и заканчивать ход за любого героя — товарищ мог зайти в Discord с телефона; существ ведёт мастер.
- **Скрытое не уходит игроку**: скрытые токены, ловушки и тайные метки сцены (`scene_secrets`), сумма скрытого броска (`log_secrets`). Строгий туман на сервере — вне объёма: стены, свет и нескрытые существа приходят всем, обзор считается в браузере.
- **Реальное время** — Supabase Realtime: изменения таблиц кампании, Broadcast (перетаскивание, линейка, пинг, бросок) и Presence на приватном канале `campaign:<id>` (только участники; публичный доступ Realtime выключен), личный канал `user:<uid>` для заявок.
- **Карты** серверной кампании — приватный бакет `maps/<campaign_id>/…`, подписанные ссылки; читают участники, пишет мастер.
- **Песочница остаётся**: «Попробовать без входа» — прежний локальный режим, ключи `rasputye-v2-*` не меняются, на сервер не переносятся.
- **Флаг**: `SERVER_ENABLED` в `dist/js/server/config.js`. Пока `false`, серверный режим включается для своего браузера ссылкой `?server=1` (выключается `?server=0`). Откат — `false`, данные на сервере не трогаются.

Ограничения бесплатного тарифа: проект засыпает после недели без активности, 500 МБ базы, 1 ГБ файлов, 200 одновременных подключений, 2 млн сообщений Realtime в месяц. Публичный (publishable) ключ лежит в `dist/` — это допустимо только вместе с RLS; служебный ключ в браузер и Git не попадает.
