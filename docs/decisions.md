## DEC-010 · 2026-10-29 · принято; заменяет DEC-006

**Хостинг — Vercel вместо Sites, публикация автоматическая из `main`.** Решение пользователя (sol0139). Сайт: https://rasputye.vercel.app, проект Vercel `rasputye` в аккаунте пользователя. GitHub Actions (`.github/workflows/deploy.yml`) гоняет `npm test` на каждый push и PR; commit в `main` с зелёными тестами выкатывает `dist/` через Vercel CLI. Красные тесты — сайт остаётся на последней рабочей версии.

Бесплатный план Vercel не публикует коммиты из приватного репозитория, если автор коммита не в команде Vercel (первый запуск, `407eb2d`, получил BLOCKED). Поэтому 2026-10-29 17:02 владелец сделал репозиторий публичным: проект без сборки, весь код и так отдаётся сайтом. После этого коммиты любого автора выкатываются (проверено: `dcf48bd` и `0535b61` — READY).

Последствия: мёрж в `main` = публикация, поэтому мёржит владелец или назначенный интегратор (см. `AGENTS.md`). Нужен секрет репозитория `VERCEL_TOKEN` (токен Vercel пользователя; добавляет владелец репо, в Git и документы не попадает). Sites больше не обновляется; отключить его и убрать `.openai/hosting.json` — отдельное решение владельца. Репозиторий и сайт публичные: всё в Git и в `dist/` видно любому, секреты и закрытые данные туда не класть.
