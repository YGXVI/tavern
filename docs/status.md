## Как взять задачу

1. Проверить активные строки, PR и свежий `main`.
2. Опубликовать свою строку заявки по правилам `AGENTS.md`; указать полный SHA базы и конкретный список файлов. Не запускать кодовую работу до видимого резервирования.
3. Создать отдельную ветку и рабочую копию. На общие участки назначить одного исполнителя; второму — независимый файл или зависимую задачу.
4. При смене объёма обновить заявку до захвата новых файлов.
5. Передать PR, проверки и ограничения. Интегратор объединяет и, если нужно, публикует по одному.
