# Словарь: продукт ↔ код

Не вводить второе имя для уже существующего понятия. Если имя меняется, обновить этот файл и места использования. Будущие поля ниже — предложение контракта, не существующий API.

| Слово в продукте | Сейчас в коде | Значение / граница |
| --- | --- | --- |
| Распутье | package `rasputye`; repo `YGXVI/tavern` | Название продукта; историческое имя репозитория не является брендом. |
| D&D 5e 2014 | подписи `5e · 2014` | Единственная выбранная редакция. |
| Кампания | `state`, `initial` в `dist/app.js` | Одна локальная кампания без `campaignId`. Не «компейн» в новых текстах. |
| Мастер | `session.role === 'master'`, `isMaster()` | В демо — режим интерфейса; в цели — администратор кампании. |
| Игрок | `session.role === 'player'` | Участник кампании с доступом к своему герою. |
| Аккаунт | отсутствует; в цели `User` | Не путать с локальной `session`. |
| Членство | отсутствует; в цели `CampaignMembership` | Связь аккаунта, кампании и роли. |
| Персонаж | сейчас токен `kind: 'hero'` | Полноценной сущности листа пока нет; в цели `Character`. |
| Противник | токен `kind: 'enemy'` | Представление участника сцены; не запись бестиария. |
| Токен | `state.tokens[]` | Маркер на карте и текущие боевые параметры. |
| Лист персонажа | сейчас `renderCharacters()` | Только имя, HP, КБ, модификатор инициативы. |
| HP / хиты | `hp`, `max` | Текущие и максимальные хиты токена. Не переименовывать `max` без миграции. |
| КБ / класс брони | `ac` | Число, хранящееся в токене. |
| Модификатор инициативы | `mod` | Прибавляется к d20. |
| Результат инициативы | `init` | Число или `null` до броска. |
| Порядок инициативы | `initiativeOrder()`, `ordered()` | Производный отсортированный список, не отдельный источник данных. |
| Раунд / текущий ход | `round`, `turn` | `turn` — индекс в порядке инициативы. |
| Карта / сцена | `#battlemap`, `state.map` | Одна сцена; `map` — загруженное изображение. |
| Туман | `state.fog` | Затемнение всей карты на этом устройстве; не отдельная видимость для игроков. |
| Сетка | `state.grid` | Локальная видимость сетки. |
| Рисунок | `state.paths[]` | Массивы точек с координатами в процентах. |
| Бросок кубов | `roll(formula)`, `doRoll()` | Парсер ограниченных формул вида `2d6+3`. |
| Журнал стола | `state.logs[]`, `renderLog()` | Броски и технические игровые события; не хроника сюжета. |
| Хроника | `state.notes`, `#notes` | Сейчас один текст мастера; не транскрипт и не публичная история. |
| Библиотека | `library[]` | Шесть встроенных записей, без внешней базы. |
| Тема | `data-theme`, `themes[]` | `midnight`, `parchment`, `graphite`, `wine`. |
| Локальный вход | `session`, `validSession()` | Сохранённый выбор роли/героя, без идентификации пользователя. |
| Резервирование задачи | строка `TASK-*` в `docs/status.md` | Видимое соглашение команды, не программный lock. |
| Публикация | Sites deployment | Не равна commit в GitHub. Vercel ещё не настроен. |
