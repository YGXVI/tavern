# Дом кампании, книга кампании, справочник (#203)

Экраны по макетам Фигмы (страницы `_master` разделы 17–18, `_player` разделы 12–13, 20–21, 23). Работают на данных кампании; формат — [data.md](data.md) (`book`, записи журнала `kind: 'book'`, ключи устройства `rasputye-book-secret:*`, `rasputye-encounters:*`, `rasputye-ref-v1`).

## Адреса

| Адрес | Экран |
| --- | --- |
| `#/camp/<кампания>` | Дом кампании: мастер — обзор (следующая сессия, отряд, заявки, приглашение, книга); игрок — свой герой, последние заметки книги, отряд, раздатки. Карточка кампании ведёт сюда, стол — `#/c/<кампания>`. Обложка и вкладки одни на все разделы — при переключении меняется только содержимое |
| `…/scenes`, `…/encounters[/<id>]`, `…/heroes`, `…/settings` | Мастер: сцены, встречи со сложностью для отряда, герои и заявки, настройки |
| `…/party`, `…/handouts` | Игрок: отряд, раздатки мастера |
| `…/book` | Книга кампании — общий блокнот: разворот фиксированной высоты, заметки текут со страницы на страницу, листаются стрелками и клавишами ← → |
| `#/maps` | «Мои карты» мастера — карты из сцен всех его кампаний |
| `#/ref[/<раздел>[/<id>]][?фильтры]` | Справочник, открыт без входа; Ctrl K — поиск по всему |
| `#/c/<кампания>/do/<действие>/…` | Действия из дома на столе: `scenes`, `new-scene`, `show/<сцена>`, `start/<сцена>`, `edit/<сцена>`, `place/<существо>`, `encounter/<встреча>[/fight]` |

## Как живёт книга

Книга — общий блокнот. Глав, сессий, пера, указателя и нитей нет.

1. Любой участник в любой момент нажимает «Новая заметка» — поверх правой страницы ложится лист.
2. Заметка — блоки: заголовок, текст, цитата. Вид блока меняется кнопками над ним; Enter в заголовке переводит к тексту, Backspace в пустом блоке убирает его, Ctrl + Enter — вписать.
3. Свою заметку автор правит и удаляет; мастер может удалить любую. Подпись — имя героя (у мастера — «Мастер») и время.
4. Заметка игрока уходит в журнал как `kind: 'book'`; клиент мастера переносит её в `book.notes`. Видят все за столом сразу.

На столе кнопка «?» слева снизу и Ctrl K открывают поиск справочника модалкой; карточка открывается поверх карты, мастер может поставить существо на сцену.

## Ограничения

- Тайное мастера (вступление, черновики раздаток, встречи) хранится только на устройстве, где его создали. Перенос между устройствами — когда появится закрытая таблица на сервере.
- Заметки игроков, которые мастер не застал, видны, пока они среди последних 120 записей журнала.
- Справочник: у заклинаний — параметры (время, дистанция, компоненты, длительность) без текста эффекта; у снаряжения — английские названия кроме оружия и доспехов; у магпредметов — английский текст SRD для 221 из 934.
