# Дом кампании, книга кампании, справочник (#203)

Экраны по макетам Фигмы (страницы `_master` разделы 17–18, `_player` разделы 12–13, 20–21, 23). Работают на данных кампании; формат — [data.md](data.md) (`book`, записи журнала `kind: 'book'`, ключи устройства `rasputye-book-*`, `rasputye-encounters:*`, `rasputye-ref-v1`).

## Адреса

| Адрес | Экран |
| --- | --- |
| `#/camp/<кампания>` | Дом кампании: мастер — обзор (следующая сессия, отряд, заявки, приглашение, книга); игрок — свой герой, «в прошлый раз», отряд, раздатки. Карточка кампании ведёт сюда, стол — `#/c/<кампания>` |
| `…/scenes`, `…/encounters[/<id>]`, `…/heroes`, `…/settings` | Мастер: сцены, встречи со сложностью для отряда, герои и заявки, настройки |
| `…/party`, `…/handouts` | Игрок: отряд, раздатки мастера |
| `…/book` | Корешок и оглавление; пустая книга — обложка и «как это работает» |
| `…/book/ch/<n>[/v/<запись>]` | Разворот главы, разночтение двух версий |
| `…/book/write[/<запись>]` | Своя версия: ленточки, голос, кто прочтёт, @-упоминания |
| `…/book/index[/<имя>]`, `…/book/threads[/<id>]`, `…/book/pen`, `…/book/bound/<n>`, `…/book/mine` | Указатель, нити, перо летописца, глава переплетена, книга героя |
| `#/maps` | «Мои карты» мастера — карты из сцен всех его кампаний |
| `#/ref[/<раздел>[/<id>]][?фильтры]` | Справочник, открыт без входа; Ctrl K — поиск по всему |
| `#/ref/classes[?want=…&mag=…&easy=1&view=table]` | Классы: галерея с подбором («в бою хочется», «магии», «первая игра») или таблица сравнения |
| `#/ref/classes/<класс>[?lvl=1–20]` | Страница класса без вкладок и свёрнутого: паспорт, старт и владения, таблица (строка — уровень и прокрутка к нему на дороге), дорога 1→20 с развилкой подкласса и полным текстом SRD; ползунок уровня сбоку |
| `#/c/<кампания>/do/<действие>/…` | Действия из дома на столе: `scenes`, `new-scene`, `show/<сцена>`, `start/<сцена>`, `edit/<сцена>`, `place/<существо>`, `encounter/<встреча>[/fight]` |

## Как живёт книга

1. Мастер нажимает «Начать игру» — открывается сессия и глава (`book.session`).
2. За столом закладка сверху (клавиша «Б») — ленточка: время, сцена, клетка героя. Ленточки видны только на устройстве автора.
3. «Завершить сессию» (меню кампании на столе) — у игроков окно «Глава закрыта на столе» с их ленточками.
4. Своя версия уходит в журнал как `kind: 'book'`; клиент мастера переплетает её в `book`. «Только мастеру» — скрытая запись журнала; мастер может запечатать её в главу (текст печати — на его устройстве) или открыть отряду.
5. Мастер переплетает главу: имя, эпиграф из записей, чернила сохнут до следующей игры или высыхают сразу. Затем передаёт перо летописцу следующей главы.

На столе кнопка «?» слева снизу и Ctrl K открывают поиск справочника модалкой; карточка открывается поверх карты, мастер может поставить существо на сцену.

Классы в справочнике: суть каждого умения класса и подкласса SRD — наш короткий пересказ по-русски (`dist/js/views/ref/class-text.js`), полный английский текст SRD раскрывается под умением. Паспорт класса (роли, сложность, главное, магия) совпадает с карточками мастера героя. «Собрать героя этим классом» отмечает класс в черновике мастера героя.

## Ограничения

- Тайное мастера (печати, личные сноски, вступление, черновики раздаток, встречи) хранится только на устройстве, где его создали. Перенос между устройствами — когда появится закрытая таблица на сервере.
- Правки игроков, которые мастер не застал, доступны, пока они среди последних 120 записей журнала.
- Справочник: у заклинаний — параметры (время, дистанция, компоненты, длительность) без текста эффекта; у снаряжения — английские названия кроме оружия и доспехов; у магпредметов — английский текст SRD для 221 из 934.
