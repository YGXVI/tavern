# Сообщение команде об обновлении процесса

Передавать после merge TASK-036; до merge это предложение в codex/process.

---

Обновляем общий процесс «Распутья». У всех участников одинаковый статус: никто не отменяет общие договорённости прямым указанием или ролью владельца репозитория. План и результат проверяет другой участник; интегратором может быть согласованный участник с доступом, кроме автора PR. Центральный чат собирает состояние, но не получает особых полномочий.

Переходим на постоянные ветки направлений: codex/network, codex/rules5e, codex/voice, claude/dev, codex/process. Для новой задачи не создаём новую ветку: сохраняем TASK-ID, Issue и OpenSpec change, работаем в ветке своего фронта. Префиксы codex/claude исторические и не назначают человека. Актуальные границы — docs/workstreams.md.

В одной ветке — один активный исполнитель и один открытый PR в main. Перед новой порцией подтягиваем main обычным merge. В PR выносим завершённую задачу или небольшую связанную пачку; не смешиваем несвязанные незавершённые работы. На время финального review фиксируем объём. После merge подтягиваем main в ту же ветку и продолжаем; ветку не удаляем. Для повторных слияний используем merge commit, без squash и force-push.

Обновите свою рабочую копию, сохранив незавершённую работу; прочитайте AGENTS.md, docs/open-spec.md, docs/workstreams.md и DEC-015, затем откройте новую сессию агента в этой копии. Готовые старые PR и рабочие копии коллег не переименовывать и не сбрасывать; переход согласовать с исполнителем. Самостоятельное слияние claude/dev из старого исключения уступает общему порядку.

Состояние задач — в Issues, требования — в OpenSpec. При изменении общих файлов заранее согласуйте границы с затронутыми участниками. При споре приостанавливаем только спорную часть. Подтверждения за коллег не ставим. Настройки GitHub и права аккаунтов этим обновлением не меняются.
