# Сообщение коллегам

Отправить после merge пакета TASK-010 в main. До merge можно проверять ветку codex/task-010-openspec, но не считать процесс установленным в main.

---

Коллеги, в «Распутье» внедрён OpenSpec 1.15.0 — общий процесс работы для нашей команды из трёх человек и агентов Codex / Claude Code.

Перед новой задачей обновите свою рабочую копию. Сначала проверьте git status и сохраните незавершённую работу в своей ветке. В чистой собственной копии выполните:

```sh
git switch main
git pull --ff-only origin main
npm ci
npm run openspec -- --version
npm run spec:validate
npm test
```

Нужен Node.js >=20.19.0 (в CI — 22). Глобальная установка OpenSpec не нужна. Если вы сейчас работаете в feature-ветке, сохраните её и согласованно подтяните свежий main в свою ветку; не сбрасывайте изменения и не переключайте чужую копию.

Прочитайте AGENTS.md и docs/open-spec.md, затем docs/status.md, docs/decisions.md, docs/data.md и спецификации своей области в openspec/specs/. CLAUDE.md подключает общие правила. docs/features/ теперь содержит указатели; будущие возможности в тексте не означают, что они уже реализованы.

Перезапустите сессию агента в корне обновлённой копии: проектные skills для Codex и команды /opsx:* для Claude Code уже в Git. Если они не появились, смотрите раздел установки docs/open-spec.md.

Новая работа: Issue по шаблону «Задача OpenSpec» → один TASK-ID и change → ответственный человек/агент, файлы, зависимости и ветка → proposal/specs/design/tasks → подтверждение плана другим участником → реализация → проверки → PR. Общие файлы и контракты заранее согласовываем; каждому — отдельная рабочая копия. Мёржит владелец или назначенный интегратор, по одному PR. Merge в main автоматически запускает публикацию.

Начало планирования в чате Claude Code: /opsx:propose task-ID-slug. В Codex: выбрать openspec-propose или вызвать $openspec-propose task-ID-slug. Все команды и порядок архивации — в docs/open-spec.md.

TASK-006–009 сохраняют прежние ID, владельцев и историю; готовые PR переписывать не нужно. Для новых задач статус ведём в Issue, центральный чат владельца собирает общую картину. OpenSpec не блокирует файлы автоматически.

После чтения подтвердите владельцу, что обновили копию и изучили правила, и укажите свою текущую задачу/ветку, используемого агента и возможные пересечения. Не назначайте коллег проверяющими или интеграторами без их согласия.
