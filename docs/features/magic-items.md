# База магических предметов
Задача TASK-006; исполнитель — Codex в сессии владельца; ветка `codex/task-006-magic-items`. Основной пакет: [../../data/magic-items/README.md](../../data/magic-items/README.md).
## Что подготовлено
Фактический каталог 934 магических предметов из раздела dnd.su для 5e 2014: два названия, тип, редкость, настройка, публикации и ссылка на карточку. 9 типов, 8 категорий редкости, 52 публикации. Снимок датирован, имеет контрольные суммы и воспроизводимо собирается в JSON/SQLite. Не заменяет полный текст правил предметов.
## Границы
Полные описания и иллюстрации не копируются. Условия настройки, эффекты, варианты редкости и цены, отсутствующие в списке, не выдумываются. Homebrew и `next.dnd.su` не импортируются. Публичный раздел `official` может содержать поддерживаемые сайтом сторонние издательства.
## Данные и интеграция
Контракт v1 определён в README пакета и `schema.sql`. `dndsu:item:<id>` — ID записи каталога, не экземпляра предмета в инвентаре. Связи публикаций многие-ко-многим. Данные read-only для приложения; домашние предметы должны жить в отдельной области и не перезаписывать этот источник.
Текущие `dist/app.js`, библиотека, сохранения, backend, CI и deploy не изменены. Подключение каталога к интерфейсу — следующая отдельная задача, с резервированием общих файлов. Общие схемы и журнал решений не редактировались, чтобы не пересечься с TASK-005 коллеги.
## Проверки
- В базе ровно столько записей, сколько в полном снимке; нет обрезания вложенных JSON-объектов.
- Нет повторов ID/URL и отсутствующих публикаций; SQLite integrity/foreign keys корректны.
- Названия с запятыми и апострофами проверяются без потери частей; 12 заголовков уточнены по карточкам.
- Русский/английский поиск и фильтры редкости/настройки возвращают записи.
- Повторная сборка даёт тот же JSON и отчёт; повреждённый снимок не принимается.
Статус интеграции отражается в `docs/status.md`: готовый PR не считается автоматически слитым или опубликованным.
