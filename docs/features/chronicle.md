# Хроника кампании и заметки

## Статус

Частично реализовано: один локальный текст мастера. Ответственный — [../status.md](../status.md).

## Сейчас

`state.notes`, поле `#notes`, секция `#notesView` в `dist/app.js` и `dist/index.html`. Автосохранение в кампанию. Навигация скрыта от игрока; обработчик записи проверяет роль. Тем не менее весь текст остаётся в localStorage устройства, поэтому безопасного разделения секретов нет. Списка записей, поиска по сессиям и публичной версии хроники нет.

## Цель и критерии

- Разделить закрытые заметки мастера и опубликованные события кампании.
- У записи есть стабильный ID, автор, время, связь с сессией и явная видимость.
- Игрок не получает закрытые тексты через API, даже если меняет параметры запроса.
- Текст мастера не перезаписывается автоматически сводкой AI.
- Черновик из транскрипта проходит проверку, редактирование и явную публикацию мастером: [recording-and-transcription.md](recording-and-transcription.md).
- При конкурентном редактировании сохраняется понятная версия либо конфликт, а не тихая потеря текста.

## Вне объёма

Автоматическое утверждение сюжетного канона, публичный блог и генерация приключения за мастера. Экспорт локальной кампании остаётся резервной копией; импорт требует отдельной задачи и проверки формата.
