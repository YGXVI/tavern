# Расчёт урона заклинаний 2014
TASK-009, Codex; контракт и отчёт: [модуль](../../modules/spell-damage/README.md).

Неизвестное возвращает ручную проверку. Исходные характеристики и текущие механики не изменяются. Источник структурированной сверки — SRD API 2014; таблица проверенных профилей не достраивается наугад.
Новые данные/тесты изолированы в `modules/spell-damage/**`, чтобы не пересекаться с TASK-007. Интеграция с UI и изменение общих контрактов остаются отдельной задачей после каталога PR #4. Это локальный чистый модуль, не опубликованная функция стола.
