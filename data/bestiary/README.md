# Бестиарий D&D 5e 2014
Единый файл `bestiary-2014.json`, схема 1.0.0. Снимок 29 октября 2026.
## Охват
- 2 906 записей с уникальными ID.
- 2 875 публичных записей индекса dnd.su: русское имя, размер, тип, мировоззрение, CR, языки/местность, источники и ссылка.
- 334 статблока SRD API 2014: 303 сопоставлены с индексом, 31 самостоятельная запись (формы/варианты и несовпадения).
- 2 572 записи содержат только метаданные, `stat_block: null`. Это не 2 906 полностью заполненных статблоков.
Статблоки: КБ с вариантами защиты, средние хиты и формула кубов, скорости по способам движения, характеристики с модификаторами, спасброски, навыки, бонус мастерства (если задан источником), сопротивления/уязвимости/иммунитеты, чувства, языки, CR/опыт, особенности, действия, реакции и легендарные действия. Бонусные действия — `null`, если в источнике нет отдельного поля.
Атаки сохраняют бонус попадания, досягаемость, обычную и максимальную дальность. Компоненты урона содержат тип и формулу кубов. Сохраняются условия, спасброски, перезарядка/лимиты, мультиатаки, выбор действий, заклинательские особенности и дополнительные поля. Неизвестное не превращается в ноль. Модуль не бросает кубы и не применяет урон к HP.
## Структура
`monsters[]` → `id`, `name`, `edition`, `identity`, `catalogue`, `stat_block`, `sources`, `review`.
`stat_block` → `armor_class`, `hit_points`, `speed`, `abilities`, `proficiencies`, `saving_throws`, `skills`, `senses`, `damage_*`, `condition_immunities`, `actions`, `reactions`, `special_abilities`, `legendary_actions`, `forms`, `additional_data`.
`actions[]` → имя/описание EN, `attack` (категория, бонус, reach, range.normal/long), `damage[]` (тип/formula/исходная структура), `saving_throw`, `usage`, `multiattack`, `subactions`, `options`, `spellcasting`, `additional_data`.
Расстояния — футы, исходный текст сохранён. Урон одного действия не равен сумме всех действий. Данные не реализуют автоматически мультиатаку, применение особенностей, расход лимитов, условия попадания, сопротивления или концентрацию заклинателя.
## Источники и сопоставление
https://dnd.su/bestiary/ — только открытый индекс 5e14, без обхода закрытых карточек, иллюстраций и копирования переводов описаний.
https://www.dnd5eapi.co/api/2014/monsters — 334 статблока SRD 2014. Это общественный API, не официальный сервис Wizards. Английские тексты SRD сохранены; русские переводы способностей не придуманы.
Привязка допускается при уникальном точном slug и совпадении размера, типа, CR и наличия исходного Monster Manual в публикациях dnd.su. Это проверка идентичности/версии, не утверждение, что каждая строка перевода совпадает с SRD. Семь несовпадений перечислены в `match_review`; такие статблоки имеют отдельный SRD ID, исходный каталог не перезаписывается. Другие варианты также остаются разными записями. Формы вампиров/оборотней не склеиваются. Следующие редакции и Homebrew не добавлялись.
Хеши источников, дата, атрибуция, сведения о покрытии и правила неизвестных значений находятся внутри JSON. Это самостоятельная выгрузка данных, пока не подключённая к UI. Старые каталоги/механики и общие файлы проекта не меняются.
## Проверки
Проверены уникальность всех ID, сохранение 2 875 строк индекса, ровно 334 уникальные привязки статблоков, совпадение HP/КБ, модификаторов характеристик, числа особенностей/действий/реакций и всех формул/условных структур урона с исходным SRD. Проверены составные действия и варианты выбора. Пример гоблина: HP 7, ЛОВ 14 (+2), скимитар 1d6+2, короткий лук 80/320 футов. Повторное чтение JSON совпадает с экспортом.
