## Что покрыто

**Игрок.** Доступные в SRD расы и варианты, двенадцать классов с вариантами SRD, развитие, мультиклассирование, мировоззрение, языки, вдохновение, предыстория, снаряжение, черта Grappler, проверки, отдых, бой, накладывание заклинаний и тексты эффектов заклинаний SRD. Приложения: состояния, исторические пантеоны, планы существования.

**Мастер.** Ловушки, болезни, безумие, объекты, яды, использование магических предметов и их описания, чтение статблоков, существа и NPC. Это материалы SRD для работы мастера, включая бестиарий; не восстановление структуры Dungeon Master’s Guide. Общие правила проверок, путешествий, боя и магии доступны в `basic-rules`.

**Базовые механики.** Развитие и мультиклассирование, предыстория, снаряжение, характеристики, проверки, преимущество и помеха, владение, спасброски, движение, окружение, отдых, бой, урон, лечение, смерть, накладывание заклинаний и состояния. Для самостоятельного создания героя дополнительно нужен `player-rules`: расы и классы в этот краткий набор не включены.

## Структура JSON

Каждый набор самодостаточен и содержит `schema_version`, `edition`, сведения об источнике и лицензии, список ограничений, `sections` и `pages`. Страницы имеют стабильный идентификатор `srd51:page:NNN`, номер и URL исходной страницы, `section_id`, обнаруженные крупные заголовки, `layout_text` и `search_text`.

`layout_text` следует показывать моноширинным шрифтом с сохранением пробелов и переносов строк. Он сохраняет две колонки и широкие таблицы исходника. Колонки читаются сначала сверху вниз слева, затем справа; широкие таблицы читаются по строкам. `search_text` предназначен для полнотекстового поиска, а не линейного чтения: две колонки в нём не разделены семантически.

Это корпус с адресацией до страницы, **не готовая база атомарных правил**. Записи заклинаний, существ, предметов, классов и формулы автоматически не нормализованы. Таблицы не преобразованы в числовые массивы, чтобы не выдавать возможную ошибку извлечения за проверенное правило. Для точной цитаты или расчёта нужно открыть связанную страницу источника. Существующие каталоги проекта и модуль урона не менялись.

## Преобразование и проверки

- Сохранён исходный PDF и его SHA-256.
- Убраны повторяющиеся нижние колонтитулы; номера страниц сохранены в полях и заголовках.
- Нормализован артефакт дефиса из текстового слоя PDF. Остальные переносы слов не исправлялись догадками.
- Сохранность букв и цифр проверяется для каждой страницы относительно текстового слоя PDF; результат в `quality-report.json`. Это не проверка порядка чтения и не верификация механик.
- Выборочно проверена страница 11 с широкой таблицей развития барда. Полная визуальная проверка всех страниц не выполнялась.

Повторное извлечение без сети:

```sh
python3 -m pip install 'pdfplumber==0.11.9'
python3 extract_srd.py
```
