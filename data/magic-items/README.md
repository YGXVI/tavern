# Магические предметы D&D 5e 2014

Снимок [официального раздела dnd.su](https://dnd.su/items/) от 29 октября 2026: **934 карточки**, **9 типов**, **8 категорий редкости**, **52 источника**. В 554 карточках указана настройка, 45 относятся к артефактам.

## Что входит

Фактические поля: русское и английское название, тип, редкость, необходимость настройки, публикации-источники, стабильный ID и ссылка на оригинальную карточку. `official` означает раздел сайта, а не утверждение, что все публикации выпущены Wizards of the Coast: сайт включает также поддерживаемых издателей.

Полные описания, переводы описаний, иллюстрации, эффекты и условия настройки не перенесены. Цена в индексном списке отсутствует и не додумывается. Для полного текста используйте `source_url`. Разрешение на перепубликацию полных текстов не установлено; источник указан для происхождения данных, не как передача лицензии на весь контент сайта.

## Поля записи JSON

```json
{
  "id": "dndsu:item:1",
  "source_id": 1,
  "name_ru": "Адамантиновый доспех",
  "name_en": "Adamantine armor",
  "edition": "5e-2014",
  "type": "armor",
  "rarity": "uncommon",
  "requires_attunement": false,
  "publication_ids": ["dndsu:publication:101"],
  "source_url": "https://dnd.su/items/1-adamantine-armor/",
  "catalog_section": "official",
  "content_status": "metadata_only"
}
```

Типы: `wondrous_item`, `weapon`, `armor`, `ring`, `potion`, `staff`, `wand`, `rod`, `scroll`.
Редкости: `common`, `uncommon`, `rare`, `very_rare`, `legendary`, `artifact`, `varies`, `no_rarity`. `no_rarity` означает «Не имеет редкости» по фильтру сайта, а не ошибку импорта. `varies` не разворачивается в выдуманные отдельные варианты предмета.

ID имеет пространство имён источника. Название не является ID. У предмета может быть несколько публикаций; они хранятся отдельно и связываются через `publication_ids` / таблицу `item_publications`. Флаг настройки не включает ограничения по классу/расе, поскольку индекс этих условий не содержит.

## Примеры SQL

```sql
-- Необычные предметы без настройки.
SELECT name_ru, name_en, source_url
FROM items
WHERE rarity = 'uncommon' AND requires_attunement = 0
ORDER BY name_ru;

-- Поиск по русскому или английскому слову.
SELECT i.id, i.name_ru, i.source_url
FROM item_search JOIN items i ON i.id = item_search.item_id
WHERE item_search MATCH 'potion OR зелье';

-- Источники артефактов.
SELECT i.name_ru, p.name AS publication
FROM items i
JOIN item_publications ip ON ip.item_id = i.id
JOIN publications p ON p.id = ip.publication_id
WHERE i.rarity = 'artifact';
```

FTS5 использует `unicode61`, без русской морфологии. Для склонений используйте подходящие префиксы (`зель*`) либо собственный поиск приложения. `ё` и `е` намеренно не объединены автоматически. SQLite требует поддержку STRICT tables (3.37+) и FTS5; сборка проверена на доступном Python 3.13/SQLite.

## Пересборка и проверка

Из корня репозитория:

```sh
python3 data/magic-items/import_catalog.py
python3 -m unittest discover -s data/magic-items -p 'test_catalog.py' -v
```

Скрипт работает без сети и без сторонних пакетов. До записи проверяет полную связь списка и метаданных, уникальность ID/URL, известные коды, источники, версию сайта и приватные карточки. Затем собирает новые файлы во временном каталоге и заменяет результаты. Снимок не меняет.

## Как получен снимок

1. Открыт раздел `/items/`, а не `next.dnd.su` и не Homebrew.
2. Из видимого каталога прочитаны 934 карточки: ID, два поисковых названия, ссылка, подписи типа/редкости и значок настройки.
3. Из DOM-скрипта этой же страницы прочитан JSON для её фильтров, без выполнения кода источника. Из HTML страницы прочитаны справочники фильтров (в работающем интерфейсе их атрибуты уже преобразованы виджетом).
4. Для 12 некорректно/неполно разделённых поисковых названий дополнительно проверены заголовки публичных карточек: индекс содержит псевдонимы и местами обрывает имя на апострофе. Сохранены только проверенные названия и ссылки в `detail_names`.
5. Импорт не обходит логин/приватность, не переносит картинки, комментарии или полный текст. Закрытый для обхода служебный `/piece/` напрямую не запрашивался; использован результат обычного открытого каталога в браузере.

При обновлении повторите сбор фактического снимка из публичного интерфейса, проверьте новые коды/источники и отдельно проверьте сомнительные заголовки. Не называйте этот снимок «автоматически актуальным» и не добавляйте полный текст в обход согласованного объёма.

## Подключение к «Распутью»

Это самостоятельный пакет данных. Он пока не подключён к библиотеке приложения и не меняет сохранения кампаний, интерфейс, CI, хостинг или серверную схему. JSON подходит для загрузчика каталога; SQLite — исходный файл данных для серверного импорта/локальных запросов, а не выбранная архитектура будущего backend. Совместимость с будущей БД согласовать отдельной задачей.
