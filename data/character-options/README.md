# Параметры создания героя SRD 5.1 (TASK-186 P1)

План r1 (`openspec/changes/task-186-character-builder`, SHA256 пакета `09d2cac7…213c`) подтверждён sol0139 для P1–P3. Этот каталог — первая часть P1: нормализованные определения **заявленного SRD-пакета**. Это не весь Player’s Handbook: других подклассов, рас, предысторий и черт здесь нет.

| Файл | Что это |
| --- | --- |
| `srd51.json` | Исходник, нормализованный вручную: классы и колонки таблиц 1–20, особенности по уровням, выборы, подклассы, расы/подрасы, Acolyte, Grappler, словари, факты методов характеристик |
| `generate.mjs` | Разворачивает исходник в публичный каталог `dist/js/data/character-options-2014.json`, проверяет схему и все ссылки; без сети, повтор даёт те же байты |
| `../../tests/character-options.test.js` | Сверка с первоисточниками и отрицательные случаи |

Воспроизведение: `node data/character-options/generate.mjs`. Ревизия каталога — SHA256 исходника, генератора, `features-2014.json` и `spells-2014.json`.

## Покрытие этой ревизии

39 определений: 12 классов × 20 строк, 12 подклассов, 9 рас, 4 подрасы, предыстория Acolyte, черта Grappler; 674 выдачи и 185 выборов, включая стартовое снаряжение (`startingEquipment` класса и предыстории; у класса оно выдаётся только первым классом, не уровнем мультикласса). Особенности — ссылки на прежние ID #176 (`srd51:feature:*`), заклинания — на прежние `dndsu:spell:*`, найденные по точному SRD API index (без нечёткого сопоставления). Старые ID `halfelf`/`halforc` и `dndsu:class:*` списков заклинаний — явные `aliases`.

## Чем проверено

- **240 строк таблиц классов**: бонус мастерства и каждая числовая ячейка (ярость, кость боевых искусств, ки, скрытая атака, очки чародейства, известные заговоры/заклинания, ячейки, ячейки договора и их круг, воззвания) сравниваются со строкой таблицы в `data/rules-2014/srd-5.1.json`.
- **ASI** — с текстом способности Ability Score Improvement каждого класса (Fighter 6/14, Rogue 10) и строкой таблицы; уровень выбора подкласса — со строкой таблицы (Cleric/Sorcerer/Warlock 1, Druid/Wizard 2, остальные 3).
- **Уровни особенностей** — с уровнем из собственного текста записи #176 («At 6th level…»); `null` в #176 нормализуется только таблицей класса (например, Divine Domain и Sorcerous Origin — 1).
- **Списки заклинаний подклассов** — имя на странице SRD подкласса и круг заклинания из каталога (Жизнь, 7 земель Круга, Преданность, Исчадие).
- **Расы/подрасы** — прибавки, размер, скорость, тёмное зрение, языки, владения, сопротивления, заклинания тифлинга по уровню персонажа — с текстом соответствующих расовых записей #176; таблица драконьего происхождения — со страницей 5.
- Хиты костей, спасброски, списки навыков классов, предпосылки мультикласса (стр. 56), Acolyte (стр. 61), словари языков/инструментов/избранных врагов/территорий.
- Мутационная проверка: намеренная порча ячейки, уровня ASI, уровня/круга расового заклинания, спасброска дыхания, скорости и списка Исчадия роняет тесты.

## Источник фактов методов характеристик

`abilityMethods` — только механические факты Player’s Basic Rules v0.3 (июнь 2015, правила 2014, стр. 7–8 PDF): стандартный набор 15/14/13/12/10/8, 4d6 без меньшего ×6, покупка 27 очков 8–15 со стоимостью 0/1/2/3/4/5/7/9. Проза, PDF и переводы не импортируются (план r1, D1). Этот источник не хранится локально, поэтому тесты проверяют только внутреннюю согласованность чисел.

## P1b

- Проекция снаряжения — [data/equipment](../equipment/README.md). Деревья стартового снаряжения 12 классов и Acolyte: выбор `equipment` с альтернативами a/b/c; строка — точный `ref` или закрытый фильтр (`{kind:'weapon',category:'martial',range:'melee'}`, `{kind:'focus',group:'holy-symbol'}`, `exclude`). «If proficient» задаётся полем `requiresProficiency`, его проверяет движок. Монеты — выдача `currency`.
- Shelter of the Faithful — публичная запись `background_feature` каталога способностей (генератор #176, pdfplumber 0.11.9). Acolyte ссылается на неё; `review.required` снят.

## Что не входит

- Опциональное стартовое богатство не закодировано.
- Формулы HP/КД/атак не дублируются: они принадлежат листу TASK-004 (#156).
- Выполнение выборов, порядок событий уровней, мультикласс и инвалидация зависимых решений — движок P2. Каталог только описывает допустимые варианты.
