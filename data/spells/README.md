# Заклинания D&D 5e 2014
База фактических параметров [раздела заклинаний dnd.su](https://dnd.su/spells/), снимок от 29 октября 2026. **524 заклинания, 46 заговоров, 8 школ, 15 публикаций-источников, 61 подкласс.**
## Содержимое
- Русское и английское название, стабильный ID, уровень 0…9 и школа.
- Точное время накладывания и условие реакции, дистанция, длительность и текст компонентов из технического заголовка карточки.
- Флаги В/С/М, текст материального компонента (если указан), концентрация и ритуал.
- Основные списки классов и опциональные расширения Tasha’s Cauldron of Everything **отдельно**.
- Связи с подклассами, типами урона из фильтра сайта и источниками; ссылка на оригинал.
Текст эффекта заклинания, раздел «На больших уровнях», иллюстрации и комментарии не включены. Разрешение на перепубликацию полных авторских описаний/переводов не установлено. База подходит для поиска и фильтрации; она не заменяет полный текст правил и не реализует автоматический расчёт эффектов.
Раздел `official` сайта включает WotC и поддерживаемые издания; это метка раздела, а не утверждение о лицензии или издателе каждой записи. `next.dnd.su` и Homebrew исключены.

## Контракт записи
`id = dndsu:spell:<id источника>`. Уровень `0` — заговор. `school` использует стабильные английские коды: `evocation`, `conjuration`, `illusion`, `necromancy`, `abjuration`, `enchantment`, `transmutation`, `divination`.
Поля `casting_time`, `range_text`, `duration_text`, `components_text` сохраняют технические параметры без угадывания чисел/единиц. `casting_category` — категория фильтра `action`, `bonus_action`, `reaction`, `minute`, `hour`; она не подменяет точное время.
`verbal`, `somatic`, `material`, `concentration`, `ritual` — булевы значения. `material_text = null` означает, что извлекаемая конкретизация материала отсутствует; это не нулевая стоимость. Расходование, стоимость, урон кубами и область действия не вычисляются из описаний.
`class_ids` — основные списки; `tce_optional_class_ids` — отдельный опциональный доступ TCE. В SQLite это таблица `spell_classes` с `access = base | tce_optional`. В справочнике 13 классов, включая родителей подклассов; собственный список в фильтре есть у 9 (`has_spell_list`). Упоминание подкласса не означает автоматическое изучение заклинания: механизм доступа задаётся правилами подкласса.
Остальные связи: `subclass_ids`, `publication_ids`, `damage_types`. Они многие-ко-многим. `damage_types` — признаки фильтра сайта, без формулы урона. Пространства имён классов и публикаций совместимы по идентификаторам источника с будущими каталогами; экземпляр заклинания/подготовка персонажа остаётся отдельной сущностью.
## Сборка и проверки
Python 3 со стандартной библиотекой, SQLite 3.37+ с FTS5:
```sh
python3 data/spells/import_catalog.py
python3 -m unittest discover -s data/spells -p 'test_catalog.py' -v
```
Снимок не загружается из сети при сборке. До замены файлов проверяются полнота списка и заголовков, IDs/URL, известные справочники и ссылки. Результат сначала собирается во временной папке; проверяются SQLite integrity и внешние ключи. FTS5 использует `unicode61`, без русской морфологии; для склонений подходят запросы с префиксом.
Примеры SQL:
```sql
-- Ритуалы без концентрации.
SELECT name_ru, level, casting_time, range_text, duration_text, source_url
FROM spells WHERE ritual = 1 AND concentration = 0;
-- Базовые заклинания волшебника первого уровня (без TCE-расширений).
SELECT s.name_ru, s.school, s.source_url
FROM spells s JOIN spell_classes c ON c.spell_id = s.id
WHERE c.class_id = 'dndsu:class:21' AND c.access = 'base' AND s.level = 1;
-- Поиск по русскому/английскому префиксу.
SELECT s.name_ru, s.name_en, s.source_url
FROM spell_search JOIN spells s ON s.id = spell_search.spell_id
WHERE spell_search MATCH 'огн* OR fire*';
```
## Происхождение и обновление
Полный JSON списка `window.LIST` прочитан из DOM-скрипта открытой страницы, без выполнения JavaScript источника. Справочники фильтров извлечены из HTML той же страницы. Для каждого заклинания прочитан только технический заголовок; сетевое чтение останавливается на границе блока описания. Служебный `/piece/` напрямую не запрашивается, авторизация и ограничения доступа не обходятся.
Для нового снимка сохраните текст DOM-скрипта списка (целиком, без усечения строки) и HTML страницы, затем:
```sh
python3 data/spells/capture_source.py --list-script /path/list-script.txt --index-html /path/index.html
python3 data/spells/import_catalog.py
```
Коллектор использует два соединения и интервал запуска запросов 0,45 секунды, учитывает 429/временные сетевые ошибки, останавливается при 401/403, кэширует уже проверенные заголовки в игнорируемом файле. Парсер не добавляет пробелы между фрагментами HTML внутри слов. Обновление требует проверки справочников и изменения ожидаемых чисел в регрессионном тесте, если состав источника изменился.
Пакет самостоятельный: текущий UI, старые сохранения, CI и хостинг не меняются. Подключение к библиотеке и листам персонажа — отдельная задача после проверки PR TASK-008.
