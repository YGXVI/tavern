# Эффекты и наложения

План — [#193](https://github.com/YGXVI/Drop.Dice/issues/193), ревизия 4, подтверждена YGXVI 07.11.2026 ([DEC-019](../../docs/decisions.md)). Тело Issue и приложения A и B — канонический текст. Здесь — что уже в коде и что решено.

## Где что лежит

| Что | Где |
|---|---|
| Весы, сборка броска, КД, урон | `dist/js/rules/effects.js` |
| Рецепты | `dist/js/data/effect-recipes.json` |
| Состояния | `dist/js/rules/condition-recipes.js`: проверены по SRD 5.1, приложение PH-A |
| Наложения в базе | таблица `effects`, в кампании `c.effects` |
| Строки → весы, концентрация, длительность | `dist/js/rules/effect-rows.js` |
| Сценарии плана как тесты | `tests/effects.test.js` |

Рецепты приложения A подтверждены и работают. Новый рецепт получает `status: "draft"`: движок показывает его только напоминанием, какие бы режимы ни стояли в частях. Человек проверил — `status` убираем, рецепт начинает менять числа.

Дополнения к языку рецепта: значение `{ "table": "$level", "rows": [[1, "1d6"], [3, "2d6"]] }` для таблиц классов и кругов, куб со знаком `"-1d4"`, `status`, `src` (`srd51` или `non-srd`), `atLeast` для `ac`. Метка `wearing:heavy-armor` и отношения `attacker:sees-target`, `attacker:relies-on-sight`, `attacker:protected-type`, `target:sees-attacker`, `target:marked-by-me`: пока их никто не поставляет, поэтому движок спрашивает.

## Ответы на вопросы §18

| № | Вопрос | Ответ |
|---|---|---|
| 1 | Переносить ли `conditions[]` в таблицу `effects` | Пока нет: состояния остаются в листе и токене, весы читают их через `conditionInstances`. Таблица готова для заклинаний и источников |
| 2 | Самодельные рецепты мастера | Да, сразу (решение YGXVI): полка как личная библиотека существ |
| 3 | История снятых наложений | Хватает журнала бросков |
| 4 | Где рецепты | `dist/js/data/effect-recipes.json`: браузер читает их напрямую |
| 5 | Обычное оружие и доспехи | Уже есть: `equipment-2014.json` |
| 6 | Исполнители | Этапы 1–2 и рецепты — `rules5e`, интерфейс — sol0139 |
| 7 | Что игрок видит о враге | Только итог (решение YGXVI) |
| 8 | Где считается чек | В браузере бросающего, мастер видит чек целиком |
| 9 | Пауза для реакций | Без паузы: кнопка у того, кто может ответить (решение YGXVI) |
| 10 | Рецепты вне SRD | Разрешены: только механика, без текста источника (решение YGXVI) |
