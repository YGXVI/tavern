# Вёрстка справочника

Запустить статический сервер из корня репозитория:

```sh
python3 -m http.server 4173 --directory dist
```

В другом терминале, с установленным Playwright и Chromium:

```sh
NODE_PATH=/path/to/node_modules BROWSER_EXECUTABLE_PATH=/usr/bin/chromium \
  node tests/browser/reference-layout/e2e.mjs
```

`REFERENCE_BASE` меняет адрес (по умолчанию `http://localhost:4173/?server=0`).
`REFERENCE_OFFLINE_FONTS=1` проверяет запасные шрифты; по умолчанию загружаются шрифты приложения.

Проверяет главную, восемь разделов, фильтры, таблицы, самые длинные названия,
поиск и его закрытие кнопкой на ширинах 1440/1024/768/390/320 px.
Проверяет подсказки правил у нижней границы экрана.
У всех классов переключает уровни 1/20 и раскрывает подробности.
Карточки со стола открывает через `openTableReference` с обеими ролями,
включая экран 844×390: нижние действия должны оставаться видимыми, а тело — прокручиваться.
Это проверка реального интерфейса с минимальным контекстом стола, без сетевого сервера.

Допустима прокрутка таблиц и лент внутри контейнера. Недопустимы выход страницы
за экран, переполнение заголовков, паспортов, фильтров и содержимого панели.
Отчёт и скриншоты сохраняются в `/tmp/ref-layout/`; ошибки геометрии или JavaScript
завершают сценарий ненулевым кодом.
