# Каталог заклинаний

## Purpose

Сохранить контракт самостоятельного пакета, интегрированного в main в TASK-006/008/009. Подключение к UI остаётся отдельной задачей.

## Requirements

### Requirement: Каталог заклинаний

Пакет данных SHALL содержать 524 заклинания D&D 5e 2014, включая 46 заговоров, с техническими параметрами карточек и раздельным базовым и опциональным TCE-доступом классов; полные эффекты и изображения не включаются.

#### Scenario: Проверка контракта

- **WHEN** каталог пересобирается офлайн из снимка
- **THEN** параметры, стабильные ID, связи и раздельный TCE-доступ сохраняются; JSON воспроизводим

### Requirement: Единый экспорт заклинаний

Репозиторий SHALL предоставлять data/spells/spells-2014.json с 524 стабильными ID существующего каталога, исходными параметрами и раздельным TCE-доступом; поддержанные формулы по уровням MUST совпадать с существующими проверенными профилями. Отсутствующее поле не означает ноль.

#### Scenario: Чтение самостоятельной выгрузки

- **WHEN** потребитель читает единый экспорт
- **THEN** он получает 524 записи и проверенные формулы с прежними статусами; экспорт не изменяет механику или UI

## Контекст и ограничения

Перенесено из прежнего feature-документа при интеграции OpenSpec. Исторические ссылки на подготовку PR не означают, что каталог подключён к интерфейсу.

# База заклинаний
TASK-008; ветка `codex/task-008-spells`. Основной пакет: [../../data/spells/README.md](../../../data/spells/README.md).
Самостоятельный каталог фактических параметров dnd.su 5e14: 524 заклинания, включая 46 заговоров; 8 школ, 15 источников и 61 подкласс. JSON и SQLite содержат два названия, уровень, школу, точные время/дистанцию/длительность/компоненты, концентрацию, ритуал и связи с классами/подклассами/публикациями. Основной доступ к классам и опциональные расширения TCE разделены.
Полные тексты эффектов, масштабирование на больших уровнях и изображения не копируются. Материальные компоненты сохраняются как технический текст, стоимость и расходование не додумываются. Коды и ограничения контракта v1 описаны в README и schema.sql пакета.
Снимок датирован и проверяем; сборка офлайн, коллектор заголовков с ограничением частоты. Проверки покрывают полный состав каталога, отсутствие усечения, связи, SQLite, поиск RU/EN, сохранение TCE-доступа отдельно, ошибки схемы и разбиение HTML внутри слов.
`dist/**`, `tests/**`, общие схемы, решения и README, занятые TASK-007 коллеги, не затрагиваются. Интеграция данных в библиотеку/лист персонажа — отдельная задача. Готовый PR не означает слияние в main или публикацию.
