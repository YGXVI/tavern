# Проверенные формулы урона

## Purpose

Сохранить контракт самостоятельного пакета, интегрированного в main в TASK-006/008/009. Подключение к UI остаётся отдельной задачей.

## Requirements

### Requirement: Проверенные формулы урона

Модуль SHALL возвращать формулы и условия для 53 проверенных профилей из 524 ID каталога; остальные 471 запись MUST возвращать manual_review без выдуманного нулевого урона. Модуль не изменяет HP, спасброски и UI.

#### Scenario: Проверка контракта

- **WHEN** вызывающий код запрашивает непроверенное заклинание
- **THEN** результат имеет статус manual_review, а не формулу 0

## Контекст и ограничения

Перенесено из прежнего feature-документа при интеграции OpenSpec. Исторические ссылки на подготовку PR не означают, что каталог подключён к интерфейсу.

# Расчёт урона заклинаний 2014
TASK-009, Codex; контракт и отчёт: [модуль](../../../modules/spell-damage/README.md).
Дополнение к каталогу PR #4 по устойчивым ID. Поддерживаемые профили рассчитывают допустимые круги до 9, заговоры по уровню персонажа, отдельные атаки/снаряды и компоненты по событиям. Неизвестное возвращает ручную проверку. Исходные характеристики и текущие механики не изменяются. Источник структурированной сверки — SRD API 2014; таблица проверенных профилей не достраивается наугад.
Новые данные/тесты изолированы в `modules/spell-damage/**`, чтобы не пересекаться с TASK-007. Интеграция с UI и изменение общих контрактов остаются отдельной задачей после каталога PR #4. Это локальный чистый модуль, не опубликованная функция стола.
