# Proposal

## Why
В main есть самостоятельный JSON934 магических предметов, но нет их каталога в интерфейсе. Классовые/расовые способности и черты хранятся в корпусе SRD и свободном тексте листа, отдельного каталога нет. Нужны два доступных справочника с поиском и безопасным добавлением в существующий лист.

TASK-129 / #129. Автор плана: YGXVI/Codex, сессия бестиария/библиотеки. Уровень L2: новые форматы каталога/личных записей и общие контракты Character. Постоянная ветка codex/library. База исследования main `33200d87f1e13a7c4180ec33ed49a0e4cfd5278c`. Хозяин направления не назначен. План подтверждают Яра и затронутый sol0139; реализации и review назначаются через #85. Интегратор результата не автор. Пока есть только поручение подготовить/согласовать план, конкретная ревизия ещё не подтверждена.

## What Changes
- Каталог способностей: классовые, подклассовые, расовые, черты и выбираемые варианты SRD5.1 с собственными стабильными ID, текстом и происхождением.
- Каталог магических предметов на существующих934 ID:221 с сопоставленными SRD-деталями,713 с метаданными;98 вложенных вариантов остаются вариантами, не новыми выдуманными ID каталога.
- Поиск RU/EN, фильтры, карточка, состояние пустого/ошибочного результата, доступ с главной и из листа, узкий экран.
- Добавление выбранного шаблона отдельным экземпляром в features[]/inventory[] TASK-004; подтверждение, совместимость старого текста, текущие права и серверная запись листа.
- Личные ручные шаблоны способностей/предметов с приватным хранением; не-SRD не добавляется в общий каталог. Копирование в лист показывает итоговую видимость.

Первый выпуск не исполняет прозу: предмет не меняет КБ/атаки, черта не добавляет триггеры, требования не разбираются как автоматическое разрешение. Экипировка, настройка и ресурсы учитываются вручную средствами листа. Следует roadmap-20261030-1 (#85), автоматические эффекты — будущие отдельные задачи.

## Capabilities
### New Capabilities
- `character-features`: нормализованный справочник способностей персонажей и проверяемое покрытие SRD.
### Modified Capabilities
- `magic-items`: интерфейс существующего каталога и честное отображение неполного покрытия.
- `library`: общий поиск и приватные пользовательские шаблоны двух типов.
- `characters`: копирование выбранного шаблона в существующий лист без потери старого текста.

## Impact
Предполагаемые новые файлы: `data/character-features/**`, `tools/character-features.mjs`, `dist/js/data/catalogue-*.json`, `dist/js/rules/catalogue-entry.js`, `dist/js/core/catalogues.js`, `dist/js/server/catalogues.js`, новые модули UI каталога и tests. SQL — новая миграция только личных шаблонов. Точные UI-пути/стыки листа назначает координатор до правок.

Зависимости: #61/TASK-004 (лист, права, CAS/идемпотентность); #97/TASK-097 (главная/библиотека), #122/#124 и #125 (не заменять Creature). Не резервируются sheet.js, store/campaign, model/sync, SQL токенов или чужие changes. Этот commit содержит только свою папку плана; код прежних задач в ветке не является частью нового approval. Публикация — последовательными review-снимками после согласования, без ручного deploy.
