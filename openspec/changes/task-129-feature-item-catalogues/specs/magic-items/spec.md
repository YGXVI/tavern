## ADDED Requirements
### Requirement: Доступный каталог магических предметов
Приложение SHALL предоставлять поиск/фильтрацию/карточку на существующих934 ID. Подтверждённые SRD-детали SHALL отличаться от metadata-only, варианты сохраняться отдельно, неизвестные технические значения MUST NOT заменяться нулями или выдуманными эффектами.

#### Scenario: Предмет только с метаданными
- **WHEN** пользователь открывает запись без SRD-описания
- **THEN** он видит известные имя/тип/редкость/настройку/источники, явное отсутствие полного описания и ссылку, без придуманной статистики

#### Scenario: Предмет с вариантами
- **WHEN** пользователь выбирает подтверждённый вариант SRD
- **THEN** карточка/добавление сохраняют ID исходного предмета и выбранный variantId, не смешивая варианты
