# Приёмка первого выпуска

Ниже будущие проверки, а не результаты тестов. Реализация ещё не разрешена по конкретному SHA этого плана.

| Сценарий | Проверяемый результат |
| --- | --- |
| Публичные предметы | Ровно934 прежних ID;221 сопоставленный SRD/713 метаданных;98 вариантов не сливаются в придуманные записи; неизвестные числа null |
| Покрытие способностей | Manifest учитывает каждый целевой блок сохранённого SRD, страницы/hash/ручной review границ; опубликованы реальные числа по видам и список неоднозначностей |
| Одноимённые способности | Имена одинаковы, scope-ID различаются; класс/подкласс/раса и варианты не смешиваются |
| Поиск | RU/EN, регистр, ё/е; совместные фильтры и сброс; исходные имена/ID не меняются |
| Сбой сети | Явная ошибка и повтор; сам лист продолжает открываться; пустой результат отличается от сбоя |
| Карточка metadata-only | Нет выдуманного описания/цены/веса/эффекта; источник и ограничения видны |
| Добавление/отмена | В превью указан герой, вариант и видимость; отмена не меняет лист; подтверждение создаёт отдельный экземпляр |
| Повтор и конфликт | Один operationId не создаёт две копии; конфликт версии не затирает чужой лист, требуется новое превью |
| Независимость экземпляров | Два одинаковых предмета имеют разные instance ID и независимые отметки; изменение шаблона не меняет их |
| Старый лист | Строки особенностей/инвентаря не теряются и не разбираются эвристически в выдуманные сущности |
| Права листа | Владелец/мастер добавляют в сборку; контролирующий ресурсами/другой игрок не получают это право от открытого перемещения |
| Личная библиотека | Чужой ID не раскрывает текст даже мастеру другой кампании; личные данные не попадают в public JSON/логи/кэш другого аккаунта |
| Копия личной записи | Видимость листа объяснена до добавления; копируется только выбранный snapshot, а не библиотека целиком |
| Лимиты и конкурентность |500 личных шаблонов суммарно,64KiB UTF-8; concurrent insert/CAS не обходят лимит и не теряют чужие данные |
| Механики | Добавление черты или экипировка предмета не запускают скрытую автоматику КБ/атак/ресурсов/условных действий |
| Интерфейс | Мастер и2 игрока,390px/клавиатура/возврат фокуса, sandbox/server; ссылки на результаты проверки, а не только screenshot |

Фактические проверки плана фиксируются в Issue #129. Для старта: SHA-подтверждение объёма людьми и ACK распределения файлов координатором. Сроки roadmap не считаются согласованием схемы/результата.
