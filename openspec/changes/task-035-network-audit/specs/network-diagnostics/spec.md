# Spec Delta

## ADDED Requirements

### Requirement: Доказательства аудита синхронизации

Отчёт аудита SHALL указывать SHA и режим реализации и SHALL различать статический вывод, эксперимент слоя хранения и проверку реальных устройств.

#### Scenario: Backend отсутствует в main

- **WHEN** реализация есть только в рабочей ветке TASK-002
- **THEN** отчёт отделяет её от main и не называет серверные сценарии пройденными без запуска

### Requirement: Воспроизводимость проверки

Программа диагностики SHALL описывать действия, ожидаемый результат и фактический статус для нескольких устройств, конфликтов, отключения/восстановления связи, присутствия, исключения участника и скрытых данных и MUST исключать секреты из доказательств.

#### Scenario: Сценарий ещё не запущен

- **WHEN** нет двух устройств или согласованной серверной реализации
- **THEN** сценарий остаётся помеченным непроверенным и содержит шаги для последующего запуска
