# Spec Delta

## ADDED Requirements

### Requirement: Действия мастера с участником

Приложение SHALL давать мастеру в настройках кампании меню участника: открыть лист его героя, передать героя игроку без героя, освободить героя («Сменить героя» — игрок выберет заново) и исключить участника с подтверждением.

#### Scenario: Игрок хочет другого героя

- **WHEN** мастер выбирает «Сменить героя» у Аси
- **THEN** её прежний герой освобождается, а Ася при входе выбирает героя заново

### Requirement: Код комнаты в отряде

Приложение SHALL показывать мастеру в виджете «Отряд» код приглашения с кнопкой копирования.

#### Scenario: Продиктовать код

- **WHEN** мастер нажимает копирование рядом с кодом комнаты
- **THEN** код в буфере обмена и подтверждение «Код скопирован»
