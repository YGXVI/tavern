## Решение
Один открытый интеграционный PR прямо из существующего постоянного направления. На время окончательного review новые посторонние задачи не попадают в diff; независимое исследование может продолжаться. Исправления и обновление main требуют нового проверяемого SHA. Очередь согласует Claude; новый фронт работы согласуют люди.

## Совместимость и переход
Исторические DEC/архивы оставлены, новое DEC-017 заменяет только требование снимков. Старые refs сохраняются до проверки полного HEAD, уникальных коммитов, PR и занятости. Новая Issue/change не создаёт Git-ветку. codex/library фиксируется без назначения хозяина; server остаётся нерешённым физическим направлением.

## Проверка и ограничения
Сверить AGENTS, реестр, руководство, шаблон и OpenSpec на отсутствие действующего требования снимков. Проверить strict OpenSpec current/archive, ссылки, diff, npm test. Runtime/SQL/CI-логику не менять. Архив не заменяет human review sol0139, merge и deploy. Откат: согласованный обратный PR документов, без удаления чужой работы.
