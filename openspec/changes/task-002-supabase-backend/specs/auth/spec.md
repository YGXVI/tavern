# Spec Delta

## MODIFIED Requirements

### Requirement: Локальный демонстрационный вход

Приложение SHALL позволять выбрать демо-аккаунт или ник без настоящего Discord OAuth; выбранный пользователь хранится отдельно для каждой вкладки. Этот вход MUST открывать только песочницу «Попробовать без входа» с локальными кампаниями браузера и не давать доступа к серверным кампаниям.

#### Scenario: Базовый сценарий

- **WHEN** пользователь выбирает демо-аккаунт
- **THEN** вкладка использует его userId, а роль определяется членством в кампании; личность сервером не проверяется

#### Scenario: Песочница отделена от сервера

- **WHEN** пользователь вошёл демо-аккаунтом
- **THEN** он видит только локальные кампании этого браузера, а серверные кампании и ссылки-приглашения на них требуют настоящего входа

## ADDED Requirements

### Requirement: Вход через Discord

Приложение SHALL входить через Discord OAuth: после согласия в Discord пользователь возвращается в приложение уже вошедшим, а его ник и аватар берутся из Discord; пароль приложение не запрашивает и не хранит.

#### Scenario: Первый вход

- **WHEN** новый пользователь нажимает «Войти через Discord» и подтверждает доступ в Discord
- **THEN** приложение создаёт его профиль с ником и аватаром из Discord и открывает список его кампаний

#### Scenario: Отказ в Discord

- **WHEN** пользователь отменяет вход на странице Discord
- **THEN** приложение возвращает его на экран входа с понятным сообщением, сессия не создаётся

### Requirement: Сессия и выход

Приложение SHALL сохранять вход между перезагрузками страницы и вкладками одного браузера до выхода или истечения сессии и MUST после «Выйти» не показывать данные серверных кампаний.

#### Scenario: Перезагрузка

- **WHEN** вошедший пользователь перезагружает страницу
- **THEN** он остаётся вошедшим и видит свои кампании без повторного входа

#### Scenario: Выход

- **WHEN** пользователь нажимает «Выйти»
- **THEN** приложение показывает экран входа, а повторное открытие ссылки на стол требует войти снова

### Requirement: Возврат по приглашению после входа

Приложение SHALL после входа через Discord, начатого со ссылки-приглашения, возвращать пользователя к этому приглашению.

#### Scenario: Игрок пришёл по ссылке

- **WHEN** невошедший пользователь открывает ссылку-приглашение и входит через Discord
- **THEN** после входа он видит карточку той же кампании с кнопкой «Присоединиться»
