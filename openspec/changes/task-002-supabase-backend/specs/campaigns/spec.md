# Spec Delta

## MODIFIED Requirements

### Requirement: Локальные кампании

Приложение SHALL поддерживать локальные кампании, приглашения, заявки и выбор героя с обменом обновлениями между вкладками одного браузера. Локальные кампании MUST оставаться в песочнице «Попробовать без входа» и не смешиваться с серверными.

#### Scenario: Базовый сценарий

- **WHEN** две вкладки этого браузера открывают одну кампанию
- **THEN** изменения передаются между вкладками; другое устройство без сервера кампанию не получает

#### Scenario: Песочница после настоящего входа

- **WHEN** пользователь, вошедший через Discord, открывает список кампаний
- **THEN** он видит только серверные кампании, где у него есть членство; локальные кампании песочницы туда не попадают и не удаляются

## ADDED Requirements

### Requirement: Серверные кампании и мастер

Приложение SHALL создавать кампанию на сервере, когда её создаёт пользователь, вошедший через Discord, и делать создателя мастером только этой кампании.

#### Scenario: Новая кампания

- **WHEN** вошедший пользователь создаёт кампанию
- **THEN** она появляется у него в разделе «Веду» на любом его устройстве, а в чужих списках её нет

### Requirement: Вступление по приглашению с другого устройства

Приложение SHALL позволять вошедшему пользователю на любом устройстве вступить в кампанию по коду или ссылке-приглашению; при ручном одобрении он ждёт решения мастера, иначе сразу становится игроком.

#### Scenario: Друг на своём компьютере

- **WHEN** игрок открывает ссылку-приглашение на своём компьютере, входит через Discord и нажимает «Присоединиться»
- **THEN** у мастера появляется заявка; после «Принять» игрок без перезагрузки попадает к выбору героя

#### Scenario: Недействительная ссылка

- **WHEN** пользователь открывает приглашение с истёкшим сроком или заменённым кодом
- **THEN** он видит экран «Приглашение недействительно», а данные кампании ему не передаются

#### Scenario: Мест нет

- **WHEN** мастер принимает заявку, а все места кампании заняты
- **THEN** сервер не добавляет игрока и мастер видит сообщение о местах

### Requirement: Уход и исключение

Приложение SHALL позволять игроку покинуть серверную кампанию, а мастеру — исключить игрока; после этого бывший участник MUST сразу терять доступ к столу, а его герой остаётся в кампании без игрока.

#### Scenario: Исключённый игрок открыт за столом

- **WHEN** мастер исключает игрока, у которого открыт стол
- **THEN** у игрока стол закрывается с сообщением, а новые изменения кампании ему больше не приходят
