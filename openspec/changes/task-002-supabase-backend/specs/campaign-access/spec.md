# Spec Delta

## Purpose

Определяет, кто и что может читать и менять в серверной кампании: роль берётся из членства, а сервер, а не интерфейс, скрывает данные мастера и отклоняет чужие изменения.

## ADDED Requirements

### Requirement: Роль определяется членством на сервере

Сервер SHALL определять роль пользователя («мастер» или «игрок») по его активному членству в конкретной кампании и MUST отклонять чтение и изменение данных кампании для того, у кого активного членства нет.

#### Scenario: Посторонний пользователь

- **WHEN** вошедший пользователь без членства запрашивает данные кампании по её идентификатору
- **THEN** сервер не возвращает ни кампанию, ни её сцены, героев и журнал

#### Scenario: Заявка ещё не одобрена

- **WHEN** пользователь с заявкой в статусе «ожидает» открывает стол кампании
- **THEN** сервер возвращает только название и обложку для экрана ожидания, без сцен, героев и журнала

#### Scenario: Подмена роли из браузера

- **WHEN** игрок отправляет запрос, меняющий свою роль на «мастер» или чужое членство
- **THEN** сервер отклоняет запрос, членство не меняется

### Requirement: Скрытые данные мастера не передаются игрокам

Сервер MUST NOT передавать игрокам токены, скрытые мастером, ловушки, заметки «только мастеру» и неоткрытые тексты для чтения вслух — ни при загрузке, ни в обновлениях реального времени.

#### Scenario: Скрытый огр

- **WHEN** мастер ставит на сцену скрытый токен, а игрок открыт на этой же сцене
- **THEN** игрок не получает данных этого токена; после «Показать игрокам» токен приходит ему обычным обновлением

#### Scenario: Ловушка

- **WHEN** игрок загружает сцену с ловушкой, которая ещё не сработала
- **THEN** в ответе сервера нет клеток, сложности и урона этой ловушки

### Requirement: Игрок меняет только своё

Сервер SHALL разрешать игроку менять своего героя, свой токен, свои рисунки и свои броски, открывать и закрывать незапертые двери, а при открытом перемещении (настройка кампании, по умолчанию включена) — положение и поворот любого видимого незакреплённого токена; изменения сцены, чужих героев, скрытности, размеров и характеристик чужих токенов и существ MUST выполнять только мастер.

#### Scenario: Чужой токен при открытом перемещении

- **WHEN** игрок двигает видимого гоблина, а мастер не выключал открытое перемещение
- **THEN** сервер сохраняет новое положение, остальные участники видят гоблина на новом месте

#### Scenario: Чужой токен при выключенном перемещении

- **WHEN** мастер выключил открытое перемещение, а игрок отправляет новое положение токена чужого героя или существа
- **THEN** сервер отклоняет изменение, у остальных участников токен не двигается

#### Scenario: Чужие характеристики

- **WHEN** игрок отправляет новые хиты или скрытность для токена существа
- **THEN** сервер отклоняет изменение

#### Scenario: Свой герой

- **WHEN** игрок меняет хиты, состояния или заметки в листе своего героя
- **THEN** изменение сохраняется и приходит мастеру и отряду

### Requirement: Разрешённые игроку действия боя

Сервер SHALL разрешать игроку внутри боя только записать свою инициативу, закончить свой ход и отправить результат своего спасброска по запросу мастера; остальные изменения боя MUST выполнять только мастер.

#### Scenario: Конец чужого хода

- **WHEN** игрок пытается передать ход, когда сейчас ходит не его герой
- **THEN** сервер отклоняет действие, очередь не меняется

### Requirement: Видимость бросков

Сервер SHALL отдавать скрытый бросок мастера только мастеру; остальные участники MUST получать лишь факт броска без результата.

#### Scenario: Скрытый бросок

- **WHEN** мастер бросает скрыто
- **THEN** игроки видят запись «Мастер бросил скрыто» без суммы и граней
