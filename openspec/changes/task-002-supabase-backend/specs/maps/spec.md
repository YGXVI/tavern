# Spec Delta

## MODIFIED Requirements

### Requirement: Локальные сцены и карта

Приложение SHALL предоставлять локальные сцены, камеру, сетку, токены, стены, двери, освещение, туман и измерения; скрытие данных является только интерфейсным. В серверной кампании те же возможности SHALL работать со сценами, хранящимися на сервере, а скрытие данных мастера MUST обеспечиваться сервером по требованиям `campaign-access`.

#### Scenario: Базовый сценарий

- **WHEN** мастер показывает сцену игрокам в соседних вкладках
- **THEN** игроки получают её локальное представление с обзором; это не серверная защита секретных данных

#### Scenario: Серверная сцена

- **WHEN** мастер серверной кампании показывает сцену, а игроки открыли стол на своих устройствах
- **THEN** игроки получают сцену с сервера, считают обзор и туман у себя и не получают скрытых мастером токенов и ловушек

## ADDED Requirements

### Requirement: Карты серверной кампании

Приложение SHALL сохранять загруженную мастером карту серверной кампании в файловом хранилище кампании так, чтобы её видели участники на других устройствах, и MUST NOT отдавать файлы карт пользователям вне кампании.

#### Scenario: Своя карта

- **WHEN** мастер загружает картинку для новой сцены и показывает сцену
- **THEN** игроки на своих компьютерах видят эту карту

#### Scenario: Ссылка на файл карты

- **WHEN** пользователь без членства в кампании пытается открыть файл её карты
- **THEN** хранилище отказывает в доступе
