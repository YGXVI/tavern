## Context

Репозиторий buildless; TASK-007 объединён. Исторические спецификации смешивали текущее поведение с целевыми критериями, а координация требовала commits в main. Внедрение не меняет исходники dist.

## Goals / Non-Goals

Единый формат требований, один ответственный на change, review плана и последовательная интеграция. Не внедрять новую архитектуру приложения, runtime-зависимости или права GitHub.

## Decisions

CLI — devDependency с exact version и lockfile, интеграции сгенерированы официальным CLI, core profile. Перенесены все 11 прежних спецификаций: Requirements описывают текущий baseline, повествовательные цели сохранены отдельным контекстом. Старые пути — указатели. Правила людей — AGENTS.md, артефактов — openspec/config.yaml. Issues — источник статуса новых задач; старые строки сохранены. CI проверяет active specs/changes и завершённость архивов в job, блокирующем deploy при ошибке.

## Risks / Trade-offs

OpenSpec не проверяет правдивость требований, согласие коллег или отсутствие общих файлов. Эти проверки выполняются review. Branch protection не включена. Архивация в ветке обновляет документы, но не доказывает интеграцию. Переход старых PR требует проверки конфликтов: их specs могут по старой договорённости добавляться в docs/features, при интеграции перенести в OpenSpec.

## Migration Plan

Первоначальная публикация была блокирована (403 + automatic review); дифф подготовлен без утверждения о резервировании. После явного разрешения владельца проверен свежий main и опубликован draft PR #7; дальше — review и закрытие замечаний. После merge участники безопасно обновляют свои копии, npm ci и читают процесс; новая сессия агента обнаруживает skills. Старые изменения не переписываются. Вариант отката — обратный PR только этого набора документов/tooling; сохранения и dist не затронуты.

## Open Questions

Кто из людей станет проверяющим и интегратором каждой следующей задачи; кто настроит защиту main. Эти назначения не выводятся из доступа к аккаунту.
