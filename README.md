# Drop Dice

Браузерный стол для D&D 5e 2014: карта, листы героев, кубы и бой в одной вкладке. Мастер и игроки играют вместе по ссылке, ничего не устанавливая.

| | Адрес | Что там |
| --- | --- | --- |
| Сайт | https://rasputye.vercel.app | Стабильная версия из `main` |
| Тестовый стенд | https://dropdice-test.vercel.app | Свежая сборка из `test`, своя база. Вход гостем: `?guest=1` |

Адрес сайта пока старый: название проекта сменилось на Drop Dice, домен переедет отдельно.

## Что умеет

**Стол.** Карта с камерой и сеткой, стены и двери, свет и тёмное зрение, туман войны, слой мастера с ловушками и метками, линейка и шаблоны областей, рисование, пинги.

**Бой.** Инициатива и ходы, хиты и состояния, спасброски, существа из бестиария, встречи.

**Кампании.** Вход через Discord, приглашение по ссылке, заявки игроков. Права проверяет база, а не интерфейс: скрытое игроку не приходит.

**Справочник.** Заклинания, существа, классы, расы, снаряжение и правила SRD 5.1 на русском.

Новое в `test`, ещё не на сайте:

- мастер создания героя, быстрый герой и перенос из Long Story Short;
- новый лист героя и повышение уровня;
- проверка сборки героя сервером;
- тайное мастера в сценах и токенах, подтверждение токенов игрока.

Что дальше — [аудит и план работ](https://github.com/YGXVI/Drop.Dice/blob/test/docs/audits/2026-11-06-stand-rules-audit.md).

## Запуск

Сборщика нет: приложение лежит в `dist/`.

```bash
npm ci
```

```bash
npm run dev
```

Откройте http://localhost:4173. Без сервера работает песочница: демо-кампании и герои хранятся в браузере.

Проверки:

```bash
npm test
```

```bash
npm run spec:validate
```

## Как устроена работа

Рабочая ветка → `test` → `main`. Изменения свободно вливаются в `test` и сами выкатываются на стенд. В `main` они попадают только с разрешения владельца, после чего зелёные тесты сами выкатывают сайт через GitHub Actions.

Одна Issue ведёт одно направление:

| --- | --- | --- |
| Конструктор героя | [#200](https://github.com/YGXVI/Drop.Dice/issues/200) | YGXVI |
